# Monocorde oscillant

Une corde de guitare sur un profilé d'aluminium, un capteur, un amplificateur et une bobine excitatrice en boucle : la corde s'entretient toute seule.

- `PCB-Coil.FCStd` : la bobine plate dessinée dans FreeCAD, gravée sur circuit imprimé.
- `pcbcoil.cb`, `pcbcoil.dxf` : le parcours d'usinage CamBam et le tracé pour la fraiseuse.
- `essais/` : session Reaper et enregistrements des essais d'un excitateur indépendant (MixPre), 2022.

Fiche du projet : https://electro-crea.com/projets/monocorde/
